# دليل لوحة التحكم — TTE

## 1. تسجيل الدخول الرئيسي
- اسم المستخدم: حساب مدير النظام.
- كلمة المرور: تُضبط خارج GitHub ولا تُحفظ في المستودع.
- بعد تسجيل الدخول تظهر لوحة التحكم.

## 2. رمز الدخول الإداري الإضافي
قسم **الإدارة الحساسة** يحتاج خطوة تحقق إضافية (PIN/كلمة مرور ثانية) على الخادم، وليس مجرد إخفاء زر في الواجهة.

يُستخدم للدخول إلى:
- مفاتيح API.
- تفعيل التداول الحقيقي.
- تغيير حدود المخاطر الحرجة.
- استيراد استراتيجية جديدة إلى الإنتاج.
- إدارة المستخدمين والصلاحيات.

## 3. المنصات والمحافظ
لكل منصة بطاقة مستقلة:
- اسم المنصة.
- API Key.
- API Secret.
- نوع البيئة: Testnet / Live.
- صلاحيات القراءة/التداول.
- حالة الاتصال.
- زر اختبار الاتصال.

**لا تضع Seed Phrase أو Private Key لمحفظة غير وصائية داخل لوحة النظام إلا بعد تصميم خزنة متخصصة لها.** لا تُدخل أي سر حقيقي في GitHub أو المحادثة.

## 4. الأسواق
- الرمز/الزوج.
- الإطار الزمني.
- الشموع OHLCV.
- الحجم والسيولة.
- السبريد.
- دفتر الأوامر عند توفره.
- المؤشرات.

## 5. الاستراتيجيات
- اختيار الاستراتيجية.
- الإصدار.
- حالة الاختبار.
- Backtest.
- Paper Trading.
- حدود الدخول والخروج.
- وقف الخسارة وجني الربح والتتبع.

## 6. الذكاء الاصطناعي
يعرض:
- الإشارة.
- الثقة.
- الأسباب والبيانات المستخدمة.
- القرار المقترح.
- قرار محرك المخاطر النهائي.

الذكاء الاصطناعي لا يملك صلاحية تجاوز محرك المخاطر.

## 7. المخاطر
- أقصى حجم للصفقة.
- أقصى تعرض.
- خسارة يومية قصوى.
- Slippage.
- عدد الأوامر.
- Circuit Breaker.
- Kill Switch.

## 8. التشغيل
الحالات المقترحة:
- 🟢 Paper Trading — آمن للاختبار.
- 🟡 Ready — اجتاز الفحوصات لكنه لا يتداول حقيقيًا.
- 🔴 Live — لا يظهر إلا بعد تفعيل صريح وإعادة تحقق.
- ⛔ Emergency Stop — يمنع إرسال أوامر جديدة.

5. الاختبارات.
6. Backtest.
