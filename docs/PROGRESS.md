# TTE — حالة المشروع

## الحالة الحالية
- المرحلة: Core + Security + Market + Paper Execution foundation
- الفرع: `foundation-v1`
- Live Trading: مقفول
- Paper Trading: مفعّل كمسار الاختبار الأول
- أسرار/API keys: لا تُحفظ في Git
- آخر CI موثق: 🟡 تشغيل اختبارات بعد دفعة الأمان الحالية

> النسبة مؤشر سير عمل وليست نسبة ضمان نجاح أو ربح.

## ما تم إنجازه في هذه الدفعة
- إضافة `pyproject.toml` لتثبيت الحزمة واكتشاف `trading*` بشكل صريح.
- تثبيت `argon2-cffi` كطبقة تجزئة كلمات مرور باستخدام Argon2id.
- إضافة اختبارات لكلمات المرور: إنشاء hash، التحقق، رفض كلمة المرور القصيرة، والتعامل الآمن مع hash غير صالح.
- تحديث CI لتثبيت المشروع واعتمادياته قبل الاختبارات.
- إضافة نموذج Audit Event غير قابل للتعديل لتسجيل الأحداث الأمنية دون وضع الأسرار داخل السجل.
- إضافة اختبارات للسجل الأمني.
- Live Trading ما زال مقفولاً افتراضياً ولا يمكن فتحه ضمن هذه المرحلة الأساسية.

## بوابة الإطلاق
لا يتم فتح Live Trading حتى تنجح اختبارات الأمان، المصادقة، الأسرار، البيانات، المخاطر، التنفيذ، Paper Trading، وفحوصات CI بدون أخطاء حرجة.

## خريطة لوحة التحكم
1. **الأمان:** كلمة مرور الدخول + تحقق إضافي للإدارة الحساسة.
2. **المنصات:** اسم المنصة، API Key، API Secret، Testnet/Live، اختبار الاتصال، الصلاحيات.
3. **المحافظ:** عنوان/معرّف المحفظة حسب نوع التكامل؛ لا يتم إدخال seed phrase أو private key في الواجهة.
4. **السوق:** الزوج، الإطار الزمني، OHLCV، الحجم، السيولة، السبريد، دفتر الأوامر.
5. **الاستراتيجيات:** اختيار/إضافة/نسخة/Backtest/Paper Test.
6. **AI:** الإشارات، التحليل، الثقة، التفسير؛ لا يتجاوز محرك المخاطر.
7. **المخاطر:** حجم الصفقة، SL/TP، التعرض، الخسارة اليومية، الانزلاق، circuit breaker.
8. **التنفيذ:** الأوامر، الحالات، partial fills، idempotency.
9. **التحكم:** تشغيل، إيقاف، إيقاف طوارئ.
10. **السجل:** Audit Log لكل تغيير وقرار وأمر.
