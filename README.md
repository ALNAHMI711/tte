# TTE — منصة التداول الذكية الآمنة

منصة تداول متعددة المنصات بواجهة عربية RTL، مع طبقات مستقلة للسوق والاستراتيجيات والذكاء الاصطناعي وإدارة المخاطر والتنفيذ والأمان.

## الوضع الآمن الافتراضي
- Paper Trading مفعّل افتراضيًا.
- Live Trading معطل حتى تفعيله صراحةً.
- لا تُستخدم صلاحيات السحب لمفاتيح المنصات.
- مفتاح إيقاف طوارئ مستقل.
- الأسرار لا تُخزن في Git ولا داخل الواجهة أو السجلات.
- الذكاء الاصطناعي لا يستطيع تجاوز محرك المخاطر.

## أقسام لوحة التحكم
1. الرئيسية والحالة.
2. المنصات والمحافظ ومفاتيح API.
3. الأسواق والرسوم والشموع والمؤشرات.
4. الاستراتيجيات والنسخ والاختبارات.
5. الذكاء الاصطناعي والإشارات.
6. إدارة المخاطر.
7. الأوامر والتنفيذ.
8. Paper Trading.
9. Live Trading.
10. السجل والتدقيق والتنبيهات.
11. إعدادات الأمان والصلاحيات.
12. تحديثات GitHub والاستراتيجيات.

> لا يوجد نظام تداول يضمن الربح أو نسبة نجاح ثابتة. الهدف هنا هو بناء نظام قابل للاختبار والتدقيق ويمنع المخاطر غير المصرح بها.
